# Publication image upload guide

Only selected publications use images. Add one landscape image for each selected publication using the exact filenames below:

- `battery-mformer.jpg`
- `pbt.jpg`
- `battery-life.png`
- `retired-battery-diagnosis.jpg`
- `magnet.jpg`

Recommended export:

- Use the exact filename and extension listed above
- 16:9 landscape crop
- 1200 × 675 px (minimum 800 × 450 px)
- sRGB color profile
- ideally under 500 KB per image

Good choices include a paper overview figure, graphical abstract, dataset illustration, model diagram, or journal cover crop. Avoid small screenshots and figures containing unreadably dense text.

Selected publications display a styled placeholder until an image is added, so missing images do not break the page. Non-selected publications are intentionally displayed as text-only cards on the Publications page.
